[%# This is a meta-template for the image editor web component. Having the HTML template in a HTML file enables easier maintenance and separation of concerns, as well as linting and validation of the HTML structure. The element (see html/js/image-editor.js) renders this template in its shadow DOM. No attribute is set on the element on purpose: it derives the image field from its closest ".select_crop" element, and the list of images / image path from "window.imageEditorConfig" (emitted by display_select_crop_init in Images.pm). %]
