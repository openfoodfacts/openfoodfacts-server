load_taxonomy (\@files)

Load one or more taxonomy files as a single taxonomy (like the build does when it concatenates several files, e.g. additives and ingredients) and compute direct parents of each entry.

Parent names are resolved to the canonical entry the same way the build does: a parent can be written with any synonym of the entry, in any language, with or without stopwords and plurals. Synonyms generated by the build by substituting synonyms inside other synonyms are not computed: parents that use them are listed in unknown_parents. Names in xx: (language-less) entries are also used as a fallback for every language.

Returns a hash ref with: - entries: list of entries, each with file, start_line, canon_id, name (first line) and parents (list of parent lines with line_num, line, canon_id, which is undef if the parent was not found) - direct_parents: canon_id -> parent canon_id -> 1 - unknown_parents: list of parents that could not be resolved

find_path ($direct_parents_ref, $from, $to)

Return a list of canonical ids going from $from to its ancestor $to, through direct parents (shortest path), or undef if $to is not an ancestor of $from. Cycles are handled.

find_redundant_parents ($taxonomy_ref)

Return the list of unnecessary parents of the taxonomy loaded with load_taxonomy().

Each item has: file, entry (canonical id), name (entry first line), parent (the unnecessary parent line hash) implied_by (the other parent line of the entry) and path (canonical ids from implied_by to parent).

A parent is not reported if both parents are ancestors of each other (cycle).

remove_lines (\@raw_lines, \%line_nums)

Return the raw lines, except the lines whose number (starting at 1) is in %line_nums.

remove_redundant_parents ($taxonomy_ref, $redundant_ref)

Rewrite the taxonomy files without the unnecessary parent lines. All other lines are kept byte for byte.
