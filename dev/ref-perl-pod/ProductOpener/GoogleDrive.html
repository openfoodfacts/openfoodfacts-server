NAME

ProductOpener::GoogleDrive - list the images of public Google Drive folders

SYNOPSIS

        my ($folder_id, $resource_key) = parse_google_drive_folder_url($url);
        my $result_ref = list_google_drive_folder_images($folder_id, $resource_key);

DESCRIPTION

Producers can share the photos of their products in a Google Drive folder shared with "anyone with the link". The producers platform lists the images of that folder (and of its subfolders) with the Google Drive API v3, and downloads them one by one.

Listing a folder needs an API key restricted to the Google Drive API, set in the GOOGLE_DRIVE_API_KEY environment variable ($google_drive_api_key in Config2.pm).

FUNCTIONS

parse_google_drive_folder_url ($url)

Extract the folder id and the resource key (if any) from the URL of a Google Drive folder.

Supported URLs:

        https://drive.google.com/drive/folders/<folder id>
        https://drive.google.com/drive/folders/<folder id>?usp=sharing
        https://drive.google.com/drive/folders/<folder id>?resourcekey=<key>&usp=drive_link
        https://drive.google.com/drive/u/0/folders/<folder id>
        https://drive.google.com/open?id=<folder id>&resourcekey=<key> (only if it is a folder: we cannot know from the URL)

Arguments

$url - the folder URL entered by the user

Return values

A list with the folder id and the resource key (undef if there is none), or an empty list if the URL is not a Google Drive folder URL.

get_google_drive_file_download_url ($file_ref)

Return the URL to download a file listed by list_google_drive_folder_images()

list_google_drive_folder_images ($folder_id, $resource_key, $api_key = $google_drive_api_key)

List the images of a public Google Drive folder and of its subfolders.

Only files with an image/* MIME type are kept: Drive reports .HEIC files as image/heif, and folders can also contain videos or documents, which are skipped.

Arguments

$folder_id

$resource_key - optional resource key of the folder (for older link-shared folders)

$api_key - optional, defaults to the configured Google Drive API key

Return value

A hash ref with:

images - array ref of hashes with id, name, path (name prefixed with the subfolder names), mime_type and resource_key, sorted by path
skipped - number of files that are not images
error - an error id if the folder could not be listed: google_drive_no_api_key, google_drive_folder_not_found, google_drive_folder_too_many_items or google_drive_api_error
error_message - details about the error, if any
