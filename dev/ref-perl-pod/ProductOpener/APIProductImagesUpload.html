NAME

ProductOpener::APIProductImageUpload - implementation of WRITE API for uploading and deleting images

DESCRIPTION

is_valid_selected_images_param($selected_ref, $response_ref)

Validate the structure of the selected parameter passed to the API v3 image upload API.

The expected structure is { <image_type> => { <image_lc> => { generation => { ... } } } }, where generation is optional. Any value that is not an object at these levels adds an API error to $response_ref with HTTP status 400 and returns 0.

Parameters

$selected_ref (input)

Reference to the selected parameter from the decoded JSON request body, or undef if omitted.

$response_ref (output)

Reference to the API response object where validation errors are added.

Return value

1 if the selected parameter is omitted or structurally valid, 0 otherwise.

upload_product_image_api($request_ref)

Process API v3 product image upload requests.
