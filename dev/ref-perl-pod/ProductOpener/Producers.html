NAME

ProductOpener::Producers - functions specific to the platform for producers

SYNOPSIS

ProductOpener::Producers contains the functions specific to the producers platform:

- Functions to import CSV / Excel files, match column names, convert to OFF csv format - Minion tasks for import and export

DESCRIPTION

..

FUNCTIONS

load_csv_or_excel_file ( $file )

Load a CSV or Excel file in a Perl structure.

- CSV files should be in UTF-8 and separated with a comma. They are processed with Text::CSV. - Excel files are first converted to CSV with gnumeric's ssconvert.

Arguments

file name with absolute path

CSV or Excel file

Return values

A hash ref with:

headers

A reference to an array of header names.

rows

A reference to an array of rows, containing each an array of column values

init_fields_columns_names_for_lang ( $l )

Populates global $fields_columns_names_for_lang for the specified language.

The function creates a hash of all the possible localized column names that we can automatically recognize, and maps them to the corresponding field in OFF.

Nutrient column names are not included in the hash: they are matched by match_nutrient_column_name() from the nutrient synonyms and the possible suffixes computed by init_nutrients_columns_names_for_lang()

The column names are computed the first time they are needed for a language.

Arguments

$l - required

Language code (string)

Return value

Reference to the column names hash.

match_nutrient_column_name ( $l, $column_id )

Match a column id to a nutrient field, by splitting it into a nutrient synonym and a suffix.

If the column id can be split in different ways, the match with the last synonym (in the order of the nutrients taxonomy) and then the last suffix is selected.

Return value

Reference to a hash with the field and value_unit, or undef if the column id does not match a nutrient.

get_column_id_field ( $l, $column_id )

Match a column id to a field in a specific language.

Return value

Reference to a hash with the field (and optionally value_unit, lc, tag), or undef if there is no match.

$GOOGLE_DRIVE_IMPORT_MAX_IMAGES

Maximum number of images imported from a Google Drive folder at once. Images after this number (in name order) are not imported.

get_running_google_drive_photos_import_job_id ( $owner_id )

Return the id of a Google Drive photos import of the owner that is queued or running, or undef

start_google_drive_photos_import ( $args_ref )

Check the URL of a Google Drive folder, and queue a minion job to import its photos.

Arguments

A hash ref with folder_url, user_id, org_id, owner_id, lc, country, add_field_values (see import_product_image_file())

Return value

A hash ref with the job_id, or with an error id: google_drive_invalid_folder_url, google_drive_no_api_key or google_drive_import_already_running (with the job_id of the running import)

$GOOGLE_DRIVE_DOWNLOAD_RETRY_DELAY

Seconds to wait before retrying the download of an image after a temporary error (HTTP 429 or 5xx)

import_photos_from_google_drive_folder ( $args_ref, $progress_callback = undef )

Import all the photos of a public Google Drive folder (and of its subfolders) to the products of the owner.

The photos are processed in the order of their names, as they would be when uploaded on the import photos page: a photo that does not have a barcode in its file name or in the image is assigned to the product of the previous photo.

Arguments

$args_ref

A hash ref with folder_id, resource_key, user_id, org_id, owner_id, lc, country and add_field_values

$progress_callback

Optional function called after each image with the results hash ref

Return value

A hash ref with:

status - "done" or "error"
error, error_message - if the folder could not be listed
images_in_folder - number of images in the folder
skipped_files - number of files that are not images (e.g. videos)
max_images - set if the folder has more images than the number of images we import at once
total, processed - number of images to process, and processed
results - array of hashes with the file name (path), code, code_source (file_name, scan, previous_photo), product_url, thumbnail_url, error and info (e.g. image already uploaded)

Minion tasks

Minion tasks that can be added to the queue by standalone scripts or the web site, that are then executed by the minion-off and minion-off-pro daemons.

The daemons are configured in /etc/systemd/system

e.g. /etc/systemd/system/minion-off.service

[Unit] Description=off minion workers After=postgresql.service

[Service] Type=simple User=off WorkingDirectory=/srv/off/scripts Environment="PERL5LIB=/srv/off/lib/" ExecStart=/srv/off/scripts/minion_producers.pl minion worker -m production -q openfoodfacts.org KillMode=process

[Install] WantedBy=multi-user.target
