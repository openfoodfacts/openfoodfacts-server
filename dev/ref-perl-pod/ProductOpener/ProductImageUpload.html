NAME

ProductOpener::ProductImageUpload - add an uploaded image file to a product, finding its barcode if needed

DESCRIPTION

Used by cgi/product_image_upload.pl (product image upload API v2, and the import photos page of the producers platform) and by the import of photos from Google Drive folders (ProductOpener::Producers).

This module is loaded by the public site for every image upload: it must not load ProductOpener::Producers or Minion (see lib/startup_apache2.pl and issue #7695).

FUNCTIONS

@photos_upload_add_fields

Fields that producers can add values to for all the products of the photos they upload (on the import photos page, and when importing photos from a Google Drive folder).

import_product_image_file ( $args_ref )

Add an image file uploaded by a user (on the producers platform, or through the product image upload API) to a product.

If the product code is not specified, we try to get it:

from the file name (e.g. 3001234567890.front_fr.jpg)
by scanning the barcode in the image
otherwise by using the code of the previous image (for producers that send a photo of the barcode, followed by photos of the other sides of the product)

The product is created if it does not exist yet. If the image type (front, ingredients etc.) is known, the image is selected.

This function is used by cgi/product_image_upload.pl and by the import of photos from a Google Drive folder.

Arguments

A hash ref with:

user_id, org_id, owner_id - the user uploading the image and the owner of the product

moderator - 1 if the user is a moderator

lc - language of the interface, used to guess the image type from the file name

country - country of the request, used if the product is created

code, imagefield - optional: product code and image field (e.g. front_fr) if they are specified

filename - name of the uploaded file

file_path - path of the image file on disk, or:

filehandle - CGI file handle of the uploaded file (read with single_param("files[]"))

tmp_file_prefix - prefix of the temporary file in which a CGI uploaded file is copied to scan its barcode

previous_code, previous_imgid - code and image id of the previous image, if any

source - "product_edit_form" if the image is uploaded through the product edit form

add_field_values - optional array ref of hashes with a field and a value, added to the product

field_values_added_for_codes - hash ref of the codes for which the field values have already been added: field values are added only once per product

Return value

A hash ref with the response of the product image upload API (status, error, files array with the filename, code, code_from_file_name, scanned_code, using_previous_code, error or info etc.)

add_field_values_to_product ( $product_id, $field_values_ref, $user_id, $org_id, $target_lc )

Add values to tags fields of a product (e.g. add a brand), as done with add_[field] parameters of the product write API v2 (cgi/product_jqm_multilingual.pl)

Arguments

$product_id

$field_values_ref - array ref of hashes with a field and a value

Fields that are not in @photos_upload_add_fields are ignored.

$user_id, $org_id

$target_lc - language of the values
